# Patcher

[Download](https://github.com/PN-7/scuomstv/releases/download/patcher-v1.3.2/Patcher-Bootstrap-win-x64-1.3.2-Install.zip) · [Release and checksums](https://github.com/PN-7/scuomstv/releases/tag/patcher-v1.3.2)

1. Extract the complete ZIP into a new folder.
2. On a new PC, install the included `VC_redist.x64.exe`.
3. Run `Start.cmd`. Initial files and required updates are downloaded automatically before launch.
4. Follow `START-HERE.txt` to select the installation folder and enter the connection settings provided by the operator.

Keep at least 50GB free. The initial download is approximately 11.89GB, followed by approximately 1.86GB of updates. Later runs download only required updates.

Existing 1.3.0 and 1.3.1 users can close the client and launcher, run the [1.3.2 upgrader](https://github.com/PN-7/scuomstv/releases/download/patcher-v1.3.2/Patcher-Upgrade-1.3.2.exe), and select the existing `Start.cmd`. Run `Start.cmd` again when the upgrade finishes. Source and licenses are included in the ZIP and the corresponding source asset.
